# Security Policy / 安全策略

## Supported versions / 支持的版本

`sure` is a code-generation library. The latest tagged release on the `main`
branch is the supported version.

`sure` 是一个代码生成库。`main` 分支上最新的发布版本即受支持版本。

## Reporting a vulnerability / 报告漏洞

If you find a security issue, please **do not** open a public issue. Instead use
GitHub's private vulnerability reporting for this repository
(Security → Report a vulnerability), or contact the maintainer privately.

如果你发现安全问题，请**不要**公开提 issue。请使用本仓库的 GitHub 私密漏洞上报
（Security → Report a vulnerability），或私下联系维护者。

Please include enough detail to reproduce the issue. You can expect an initial
response within a reasonable time frame.

请提供足以复现问题的细节。你会在合理时间内收到初步回复。
