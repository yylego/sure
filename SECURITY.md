# Security Notes / 安全策略

## Supported versions / 支持的版本

`sure` is a code-generation package. The latest tagged release on the `main` branch is the supported version.

`sure` 是一个代码生成库。`main` 分支上最新的发布版本即受支持版本。

## Reporting a flaw / 报告漏洞

On finding a security flaw, please **do not** open a public issue. Instead use GitHub's private vulnerability reporting on this repo (Security → Report a vulnerability), / contact the maintainers in private.

如果你发现安全问题，请**不要**公开提 issue。请使用本仓库的 GitHub 私密漏洞上报（Security → Report a vulnerability），或私下联系维护者。

Please include enough details to reproduce the issue. Expect a first response within a reasonable time frame.

请提供足以复现问题的细节。你会在合理时间内收到初步回复。
